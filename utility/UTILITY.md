This folder is meant to hold and organize information, techniques, insights and methods for interacting with AI tools, specifically aimed at the interface with LLM or Native Language Interfaces.

Analysis and development is provided in uniform structure to make the base easily understandable, useable, and cross-functional. Files are in either .md form or direct code or math snippets. The general form of each .md file is:
 ### 1. Introduction/Discussion: defining the problem or need, defining the state of art and edges.
 ### 2. Method/Development: developing the approach and methods, defining the tool as a stepwise process of logic to math in easily understandable (high school reading and comprehension level) language.
 ### 3. A human readable machine actionable bridge such as json
 ### 4. A pure mathematical or code object that optimizes the functionality and extensibility in a deployable form (ie. python or a transform method)

The folder will be organized overall to optimize cross-functionality as a working objective. These categories are loose but indicative of the potential parsing and difficulties:
 ### 1. Tools and toolsets
 ### 2. Cheats and Hacks
 ### 3. Methods and Perspectives
 ### 4. Other Stuff
The meta work is creating relational connections as the base grows.
